# 声乐试唱的词格、合唱与分谱交接

把字面读词带到真正能合唱的 Python 工具：同一份曲词、读音词条、拍位与分排意见，
经规则解析与联合校验后，给钢琴伴奏、各声部和指导教师输出**同一次选择**的
总报告、分谱、钢琴总览和机器可读清单。仅使用 Python 3.11 标准库。

## 资料约定

每份资料为 UTF-8 JSON 数组，id 在同一份资料内唯一，原始文字按收到的形式保留。

- `data/score.json`：排练总谱。`bar` 为小节号，`slots` 明列拍位和能否承载新音节
  （`can_start=false` 即不可拆单音位）；`shared` 是需要使用同一拍位的合唱标记
  （共同收音、换气重入等）。
- `data/words.json`：曲词与地区读音。`stress` 为从 1 计的重音音节序号；
  曲词按 `voice`、`bars` 定位，同一字词可以重复出现。
- `data/notes.json`：分排笔记，`at` 的顺序是提交时间。带 `approval` 的是分排
  确认回执，不代表合唱总排已确认。

## 工具做了什么

1. **读音与音节**：一个字可有多种读法（如「那厢」甲调 `na/xiang` 两音节、
   乙调 `niang` 一音节），不同读法改变音节数、重音与辅音落点；入声按
   `p/t/k` 韵尾识别（`hiap` 或 `hia-p` 两种记法）。
2. **出现辨认**：同一字词反复出现时，按声部、小节范围、所在小句和出现次序
   区分是哪一次，所有结果保留原词记录 id 与字符下标。
3. **拍位排布**：每个音节必须落在 `can_start=true` 的拍位；一个字可拉长覆盖
   多拍，但两个音节不能挤同一个不可拆单音位，冲突即 `UNSLOTTABLE`，该唱法不可采用。
4. **换气与语义作用域**：否定词与被修饰词之间换气会改变听众理解（`NEGATION_SCOPE`）；
   引语更正后，换气点挪到完整引语之后。
5. **合唱对齐**：共有尾音必须同拍收在同字、换气重入必须同拍且辅音落点一致、
   入声同拍收短；独唱段保留教师弹性，只做本声部提示。
6. **确认纪律**：分排确认只约束本声部；共享段一位教师接受新读音，不代表其他
   声部已接受随之移动的落点。共享落点无法兼容时退回相关声部一起确认，原来已
   确认且仍合法的整段继续练，已认可的其他段照常发给学员。
7. **更正追溯**：后来纠正某句是引语或某字改读时，按原词 id 与字符下标定位
   需要重练的位置，区分已排练落点与新安排落点。

## 使用

```sh
# 预检：资料校验、意见解析、冲突一览
python3 -m hechang check

# 生成方案（不指定 -o 时打印到标准输出；有阻断问题时退出码为 2）
python3 -m hechang plan -o build/sel2

# 只看各声部分谱
python3 -m hechang scores

# 针对某条更正笔记定位重练位置
python3 -m hechang trace N5
python3 -m hechang trace N5 --json
```

`plan -o` 产出：

| 文件 | 读者 | 内容 |
| --- | --- | --- |
| `conductor_report.txt` | 指导教师 | 逐段状态、具体冲突、备选唱法及否决原因 |
| `piano_overview.txt` | 钢琴伴奏/指导 | 按小节横向对齐各声部落点 |
| `part_<声部>.txt` | 各声部学员 | 带拍位、重音、入声、词界、换气与原词定位的分谱 |
| `manifest.json` | 系统交接 | 一次选择、逐段状态、逐拍定位（word_id + char_index） |

所有分谱抬头都带同一个 `selection_id`：负责人选定后，各声部拿到的分谱必然
对应同一次选择，不会混入旧版。

## 状态与退出码

- 段状态：`已确认` / `试唱` / `待声部确认` / `可继续练`。
- `plan` 在存在阻断问题（不可拆音位、共有尾音/重入不兼容、重音锁等）时
  退出码为 2，并把问题交回老师；已认可的其他段仍写入输出可发学员。
- 解析不出的笔记不会被静默丢弃，而以 `UNKNOWN` 保留原文，等待教师确认。
